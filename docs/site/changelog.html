Historique des versions et des features ajoutées.

v1.0

Septembre 2026 Stable

Première release publique. Multi-device, onglets chrome-style, pipeline scrcpy v4 brut, décodage FFmpeg in-app.

✨ Nouveautés

  • Décodage H.264/AV1 via FFmpeg.AutoGen 8.1.0 (FFmpeg 8.1.2)
  • Pipeline scrcpy v4.0 brut (raw_stream=true) — aucune dépendance externe à scrcpy.exe
  • Multi-device : connexion simultanée de plusieurs Android
  • Hub avec onglets façon navigateur : un onglet par device en miroir
  • Indicateur live + compteur FPS sur chaque onglet
  • Connexion USB et Wi-Fi automatique
  • 261 tests unitaires (Core + Desktop), Debug + Release verts

🔧 Technique

  • FFmpeg.Shared 8.1.2 vendoré (LGPL 2.1)
  • scrcpy-server.jar 4.0 vendoré
  • AdvancedSharpAdbClient 3.0.9 pour ADB
  • Installer MSI WiX 4 — 19 fichiers, ~640 Ko
