Installation en 3 étapes

  1. 1

    Télécharge le MSI

    Clique sur le bouton ci-dessus. Le fichier RidersMirroring.Setup.msi se télécharge.

  2. 2

    Lance l'installateur

    Double-clique sur le fichier. Si Windows SmartScreen te demande confirmation, clique sur "Informations complémentaires" → "Exécuter quand même".

  3. 3

    Connecte ton téléphone

    Branche ton Android en USB (active le débogage USB dans les options développeur), ou connecte-le en Wi-Fi. Le hub détecte automatiquement tes devices.
