Riders Mirroring pushes the upstream scrcpy-server.jar onto Android devices
and renders its video stream locally. We do not modify or relink the jar;
it is used unmodified as a third-party process.

Stream protocol (12-byte media packet header, codec-id ASCII encoding,
session flag bits) is implemented independently in Riders Mirroring's
ScrcpyStreamParser — no upstream source code is copied. The upstream
scrcpy logo is NOT bundled with Riders Mirroring; reference docs only
cite the upstream URL.
